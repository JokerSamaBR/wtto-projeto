Trabalho preparado



Executar com Codex no seu computador


Instale o Codex CLI, autentique sua conta e instale o servidor codex-imagegen-mcp. Dentro da pasta do servidor MCP, execute:


uv run python scripts/smoke_client.py /caminho/para/wyo_imagegen_job.json


O JSON exportado usa os argumentos oficiais de generate_image. Ajuste os caminhos locais antes de executar. O backend padrão usa os limites do seu plano Codex; não requer chave de API. Nenhuma geração é gratuita e ilimitada por garantia.


Para sheets de oito direções, gere oito imagens realmente distintas e depois use o Sprite Sheet Lab. Não use espelhamento para inventar vistas.
